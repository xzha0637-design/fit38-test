# AI Usage Statement

**Project:** Signal Review - FIT5238 Team SA34
**Scope:** Iteration 1 foundation and Iteration 2 repository/documentation updates
**Last updated:** 9 August 2026

## Declaration

Generative AI assistance, including OpenAI Codex, was used during this project.
AI-assisted output may appear in source-code drafts, automated tests,
documentation, code comments, troubleshooting steps and document formatting.
The tool supported development; it did not replace the team's responsibility
for requirements, design decisions, verification or the submitted work.

## How AI assistance was used

- translating team-approved User Stories and Acceptance Criteria into proposed
  implementation and test changes;
- suggesting and revising Python, JavaScript, HTML and CSS;
- proposing automated tests, browser checks and controlled error cases;
- improving technical documentation, plain-language explanations and code
  docstrings/JSDoc; and
- helping run repeatable checks and prepare the Testing Plan PDF.

For the current Iteration 2 branch, AI assistance also supported the tutor-
feedback UI review, risk-score wording, mobile batch-layout diagnosis, CSV and
privacy safeguards, CI configuration, regression tests and documentation
consistency review.

## Human control and verification

- Team members define the product scope, Acceptance Criteria and final design
  choices.
- A team member must review the final diff before merge and remains accountable
  for every submitted file, including AI-assisted material.
- Proposed changes are checked against the repository's mapped tests, Run Sheet,
  browser interaction plan and documented privacy/human-oversight rules.
- Passing automated tests is supporting evidence, not a substitute for human
  review, GUI testing or target-user feedback.
- Git history records the team member who reviewed and submitted each change; it
  does not imply that every line was typed without assistance.

## Data and security boundaries

AI assistance must not receive or reproduce passwords, access tokens, API keys,
private customer data or live personal-account data. This project uses the
tracked offline demonstration fixtures and public project documentation.

## Known limitation

Generative AI can produce incomplete, incorrect or misleading output. The team
therefore treats AI suggestions as drafts and accepts them only after code
review, relevant tests and documented verification.
