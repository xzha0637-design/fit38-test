Model information and limitations

Read this evidence before relying on an assessment. Signal Review is a human-review aid for public Twitter/X account data, not an enforcement or account-classification system.

Automated enforcement is prohibited. Results must not suspend, restrict, report, or otherwise act on an account.

Public-data feature schema

The model uses twelve derived or public-profile fields:

  • account age, follower count, following count, and their ratio;
  • tweet count and posting frequency;
  • description length, username length, and profile completeness;
  • verified status, default-profile-image use, and description presence.

Full follower/following graph features, graph topology, private data, and content-semantic features are excluded.

Calibration evidence
Low/Medium/High boundaries were selected on a separate validation split of 5,929 records (recorded validation mean cost: 0.266149). No formal probability-calibration or reliability metric is currently available.

These figures describe the bundled datasets and are not evidence of performance on current live or external populations.

Known risks and unsupported uses

  • Cross-dataset limits: performance has not been validated on an independent external dataset.
  • Prevalence shift: different bot/human proportions can change precision and error rates.
  • Concept drift: account behaviour and platform conventions can change after the evaluation data period.
  • False positives: legitimate accounts may receive elevated scores; the recorded precision shows this risk is material.
  • Excluded graph evidence: coordinated-network signals cannot be inferred from this feature set.

Do not use the output as proof that an account is automated, harmful, fraudulent, or policy-violating. Do not use it for automated moderation, sanctions, reporting, or enforcement.
